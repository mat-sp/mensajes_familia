# Generador de mensajes a familias

Web estática desarrollada por Diego Bernal Montañés.

## Publicación con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube a la raíz del repositorio:
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. En GitHub, entra en **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Guarda los cambios.
6. GitHub mostrará la URL pública de la web cuando termine el despliegue.

El archivo `index.html` contiene toda la web. No necesita servidor, base de datos ni dependencias externas.

## Actualizaciones

Para actualizar la web, sustituye el archivo `index.html` por la nueva versión y confirma los cambios en GitHub.
